# Integration status

## Functional without external credentials
- Manager health polling
- CEO report filtering
- Commerce event/opportunity API
- Media content queue API
- SaaS V3 local telemetry
- Finance Command Center local/mock modes
- Master hierarchy UI
- Integrity and health scripts

## Requires external credentials/endpoints
- OpenAI / Anthropic
- WhatsApp provider
- Resend email
- Amazon/Shopify/marketplace APIs
- YouTube/social publishing APIs
- Real trading/RPC/exchange credentials
- Real SaaS product URLs/webhook secrets

## Safety
External actions must be explicitly enabled by the corresponding adapter and policy layer.
